# Karaz Tiaras

**Karaz Tiaras** is an affordable luxury brand offering elegant bridal and occasion accessories that blend timeless beauty with modern charm. Our collection also includes delightful pieces for kids and little princesses, bringing a touch of grace to every special occasion.

## ✨ Features
- Responsive design for desktop, tablet, and mobile
- Product gallery for bridal tiaras and kids' accessories
- Contact form for custom inquiries
- Instagram integration for latest collections
- Fast loading with optimized images

## 🚀 Quick Start
1. **Fork/Clone** this repository
2. Edit content in `/src` (images, text, colors)
3. Preview locally: Open `index.html` in browser
4. Deploy: Push to `main` → auto-publishes to GitHub Pages
