# Karaz Tiaras

**Karaz Tiaras** is an affordable luxury brand offering elegant bridal and occasion accessories that blend timeless beauty with modern charm. Our collection also includes delightful pieces for kids and little princesses, bringing a touch of grace to every special occasion.

[![Live Site](https://img.shields.io/badge/Live-KarazTiaras.github.io/Karaztiaras-gold?style=flat&logo=github)](https://KarazTiaras.github.io/Karaztiaras)

## ✨ Features
- Responsive design (desktop, tablet, mobile)
- Gold luxury theme with hover effects
- Product gallery for bridal & kids collections
- Fast loading, SEO optimized
- Professional Instagram integration

## 🚀 Quick Start
1. Fork/Clone this repository
2. Open `index.html` in browser to preview
3. Edit content, images, colors
4. Push to `main` → auto-deploys to GitHub Pages
